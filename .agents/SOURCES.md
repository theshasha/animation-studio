本项目加入以下 5 个技能，正文与配套资料保留原文。

| 技能 | 来源 | 版本依据 |

Remotion 保留总入口完整的配套目录，包括按需引用的参考、示例脚本和资源。嵌套的 `REFERENCE.md` 不会作为额外技能注册。这些内容不代表工作室已经安装其中提及的依赖或服务。

GSAP 的 MIT 许可证随三个技能分别保留。所选 Remotion skills 提交中未包含独立许可证文件，不自行推定许可类型；`writing-for-agents` 保留来源文件原文与作者信息。

技能随项目纳入 Git 版本管理。更新时维护来源、版本或提交号，以及必要的本地修改说明；恢复旧版本使用 Git 历史。

恢复与更新步骤见 [安装与更新指南](../docs/setup-and-updates.md)。本文件维护当前来源；项目特有约定留在 `AGENTS.md` 与作品文档中，第三方原文保持可核对。
