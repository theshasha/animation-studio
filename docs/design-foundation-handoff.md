### 影响后续判断的发现

- **Mocubix：**使用 Fontshare、Geist Mono 等字体与 Commons 图像；公共 CSS 变量、小型脚本、原生滚动动画及独立 Web Component 组织效果。素材脚本保存来源与尺寸，并可提取图像配色。其项目专用审美与浏览器约束不是本项目规则。
- **Relume Icons：**可确认 Relative 字体、Iconify、Vue、Vite、UnoCSS 等发布文件证据。它支持 Webflow 输出，但不是因此用 Webflow 构建。未确认定制站点的公开源码仓库，与 Icônes 的具体派生版本也未确认。
- **Radix：**官网使用自身组件和颜色体系，同时增加商业字体、字距及 CSS 动效定制。安装 Themes 不等于获得官网外观，使用其组件也不要求 Next.js。
- **视频适配：**字体、SVG、颜色和部分展示组件可以共享；滚动时间轴、实时循环、随机及有历史状态的动画需要改为可确定的帧驱动。音频仍使用用户提供或选定的现成素材。

资源调查没有安装测试全部候选工具，也没有逐项审查所有素材授权。详见资源指南中区分的证据与待核查事项。

### 建议的讨论顺序

1. **资源查阅如何进入创作流程：**建议在项目指引加入简短入口，明确设计前查阅资源指南、继续作品时沿用已确认配置。具体措辞及修改范围待确认。
2. **作品记录到什么程度：**建议在现有作品说明中记录字体与中文覆盖、颜色用途、排版、图标规格、素材来源及动效参考。是否需要统一结构、何时需要代码配置，继续讨论。
3. **首批资源是否已有使用场景：**有明确作品或界面需要时，再决定字体、图标集、Radix 接入范围及验证方法。当前没有待实施的新作品需求。
4. **出现实际复用后如何提取：**按现有目录约定，将公用展示组件、SVG、纯计算函数或处理脚本放到适合的位置。公共 API 由实际需求确定。

### 后续方案的完成标准

- 开始作品时能定位资源，并说明具体选用项及其用途。
- 已确认的视觉选择能够被后续会话找到并沿用。
- 共享资源和公共实现服务多个作品，不使全部作品被迫采用同一外观。
- 网页与视频共享适合的视觉内容，分别处理交互和帧驱动。
